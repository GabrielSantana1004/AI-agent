# Roadmap

## Fase 1 - ID-01: Fundação
- Definir identidade visual
- Estruturar layout base
- Preparar navegação inicial

## Fase 2 - ID-02: Conteúdo institucional
- Implementar catálogo de cursos
- Inserir matrizes curriculares
- Definir descrições e disciplinas

## Fase 3 - ID-03: Administração
- Criar login de gestão
- Implementar cadastro de notícias
- Publicar notícias na página inicial

## Fase 4 - ID-04: Qualidade
- Validar responsividade mobile
- Testar navegadores modernos
- Revisar fluxo geral

Este roadmap está organizado em fases incrementais para entregar o site institucional com progresso funcional e controle de evolução.
