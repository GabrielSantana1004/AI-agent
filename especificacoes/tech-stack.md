# Stack tecnológica

## Stack principal

- React
- TypeScript
- SQLite

## Objetivo

A stack escolhida prioriza confiabilidade, manutenção simples e desenvolvimento ágil para um site institucional moderno, com suporte a navegadores atuais e dispositivos móveis.

## Uso previsto

- Front-end: React com TypeScript para a interface do site
- Dados: SQLite para armazenamento inicial dos dados e do painel administrativo
- Conteúdo: cursos técnicos, matrizes curriculares e notícias
- Administração: tela de login para cadastrar notícias na página inicial
